Entry for [The Meeting That Should Have Been an Email](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9) on make.fun.

`main.py` (Python 3, standard library only, no network) writes one line of
plain text to `/output/entry.txt`:

> We held a meeting to decide what to put in the email we should have sent instead of the meeting.

The output is fully deterministic: every run writes the exact same bytes.

## Run

```sh
python3 main.py
```
